# Tangible Coding Studio WebMCP Codex Project

## Purpose

This folder is the complete starting inventory for the Codex project responsible for designing, building, testing, deploying and submitting **Tangible Coding Studio: Mission Builder** to the 2026 OpenAI WebMCP Challenge.

## First actions in the new Codex project

1. Create or select the Git repository `tangible-coding-webmcp-mission-builder`.
2. Copy this starter pack into the repository root.
3. Rename this file to `README.md` after confirming the public wording.
4. Keep `AGENTS.md` in the repository root; Codex reads it before work.
5. Read these files in order:
   - `docs/SOURCE-OF-TRUTH.md`
   - `docs/PROPOSAL.md`
   - `docs/FORMAL-SPECIFICATION.md`
   - `docs/TIMELINE-AND-ACTION-PLAN.md`
   - `docs/TOOLS-AND-ACCOUNTS.md`
   - `docs/DECISION-LOG.md`
   - `docs/SUBMISSION-INVENTORY.md`
6. Paste `prompts/CODEX-MASTER-PROMPT.md` into the first Codex task.
7. Ask Codex to inspect the repository and report blockers before creating application code.
8. Confirm the 2026-08-28 record that Ian Cameron's written WhatsApp authorisation is retained privately by Bun Tang; do not add the evidence to the repository.

When project documents conflict, use this order:
